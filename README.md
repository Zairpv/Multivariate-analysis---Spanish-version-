# 📊 Multivariate Analysis — Spanish Version

Este repositorio contiene una colección de scripts en R y documentos técnicos en español que abordan diversos métodos de análisis multivariado aplicados a datos ambientales y sociales. Cada análisis cuenta con su **script en R** y su **reporte explicativo en PDF**, facilitando la comprensión paso a paso.

## 📂 Estructura del repositorio

| Carpeta / Archivo | Descripción |
|-------------------|-------------|
| `scripts/`        | Scripts en R para cada uno de los análisis multivariados incluidos. |
| `docs/`           | Informes técnicos en PDF que explican la teoría, implementación y resultados de cada análisis. |
| `README.md`       | Descripción general del repositorio. |

## 🔍 Objetivo

El objetivo de este repositorio es facilitar el aprendizaje y la aplicación práctica de los principales métodos multivariados a través de ejemplos reproducibles y bien documentados.

Todos los códigos pueden ser ejecutados directamente en RStudio y los resultados comparados con los reportes PDF.
